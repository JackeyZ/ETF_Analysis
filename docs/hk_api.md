# 港股数据源调研（Spike 产出）

> 调研日期：2026-09-10　结论用于「港股数据源与独立港股数据库」开发。
> 所有请求均为免费公开接口，无需注册。

## 0. 结论摘要

| 能力 | 结论 | 方案 |
|---|---|---|
| 港股历史 PE | **没有任何现成接口** | 自己算：`PE = 当日总市值 ÷ 当日已披露的最新 TTM 股东应占溢利` |
| 港股每日收盘价 | ✅ 可用 | `push2his` K 线，`secid=116.xxxxx` |
| 港股股本 / 市值 | ✅ 可用 | `push2` `f84` 总股本、`f116` 总市值 |
| 港股归母净利润 | ✅ 可用 | `RPT_HKF10_FN_MAININDICATOR`（宽表，一期一行） |
| 港股全市场代码清单 | ✅ 可用 | `push2` clist，约 4685 条（含非股票，需过滤） |
| 港股财报披露日 | ❌ **没有** | 退化为法定披露截止日（中报 8/31、年报 4/30） |

**最关键的一条**：东财估值库 `RPT_VALUEANALYSIS_DET`（A 股在用的那个）**完全不含港股**，
`SECURITY_CODE` 与 `SECUCODE` 两种写法都查不到。所以 A 股那套「直接下载历史 PE_TTM」在港股走不通，
必须自算。好消息是自算公式与 A 股 `peg.py:912` 现有的 `pe = mktcap / np_ttm` **完全同构**。

## 2. 可用接口

### 2.1 全市场港股代码清单

```
GET https://push2.eastmoney.com/api/qt/clist/get
    ?pn=1&pz=500&po=0&np=1&fltt=2&invt=2&fid=f12
    &fs=m:128+t:1,m:128+t:2,m:128+t:3,m:128+t:4
    &fields=f12,f14,f2,f3,f20,f21
```

实测（2026-09-10）：

| `fs` | total |
|---|---|
| `m:128+t:1` | 448 |
| `m:128+t:2` | 1317 |
| `m:128+t:3` | 2610 |
| `m:128+t:4` | 310 |
| **四项合计** | **4685** |
| `m:128`（不加 t: 过滤） | 18067（含权证、牛熊证等非股票，**不要用**） |

返回样例：

```json
{"f2": 69.9, "f3": -0.64, "f12": "00001", "f14": "长和",
 "f20": 267720110550, "f21": 267720110550}
```

- `f12` 代码、`f14` 名称、`f2` 最新价、`f20` 总市值、`f21` 流通市值
- 抽样 100 条：**100% 是 5 位数字代码，且都有市值**
- 4685 里混有非股票品种，实际可投资股票约 2600~3000 只

> 与 A 股 `fetch_etf_list` 用同一个 `http_get`（带节点轮换 + 全局限流）。
> **必须走 `ds.http_get`**：探测时直接用 `urllib` 拿 clist 一律 `RemoteDisconnected`。

### 2.2 单只港股实时行情 / 股本 / 市值

```
GET https://push2.eastmoney.com/api/qt/stock/get
    ?secid=116.00700&fields=f57,f58,f43,f84,f85,f116,f117,f162,f167
```

实测：

```json
{"f43":425600,"f57":"00700","f58":"腾讯控股",
 "f84":9103161440.0,"f85":9103161440.0,
 "f116":3874305508864.0,"f117":3874305508864.0,
 "f162":0,"f167":296}
```

| 字段 | 含义 | 注意 |
|---|---|---|
| `f43` | 最新价 | **放大 1000 倍**，425600 → 425.6 HKD |
| `f84` | 总股本 | 9,103,161,440 股 |
| `f85` | 流通股本 | 与 f84 相同（港股一般无流通限制） |
| `f116` | 总市值 | 3,874,305,508,864 → 3.87 万亿 **HKD** |
| `f162` | 市盈率 TTM | **恒为 0，不可用** |

自洽校验：`425.6 × 9,103,161,440 = 3.8743e12` ✅ 说明市值以 **HKD** 计价。

```
"2026-06-02,438.000,481.600,484.800,437.400,101874275,47789124352.000,10.87,10.46,45.600,1.12"
```

> 说明 `push2his` 比 `datacenter` 敏感得多，实现时必须：

### 2.4 港股财报（核心）

```
GET https://datacenter.eastmoney.com/securities/api/data/v1/get
    ?reportName=RPT_HKF10_FN_MAININDICATOR&columns=ALL
    &filter=(SECUCODE="00700.HK")&pageNumber=1&pageSize=500
    &sortColumns=REPORT_DATE&sortTypes=-1&source=WEB&client=PC
```

**宽表，一期一行**（对 00700 共 96 期）。关键字段：

| 字段 | 含义 |
|---|---|
| `SECUCODE` / `SECURITY_CODE` | `00700.HK` / `00700` |
| `REPORT_DATE` / `STD_REPORT_DATE` | 报告期 |
| `REPORT_TYPE` | `2026年中报` / `2025年年报` / `2026年一季报` … |
| **`HOLDER_PROFIT`** | **股东应占溢利 = 归母净利润（累计值）** |
| `HOLDER_PROFIT_YOY` | 同比 % |
| `HOLDER_PROFIT_SQ` / `REPORT_DATE_SQ` | 上年同期值 / 同期报告日 |
| `OPERATE_INCOME` | 营业收入 |
| `BASIC_EPS` / `EPS_TTM` | 每股收益 / TTM 每股收益 |
| `ISSUED_COMMON_SHARES` | **已发行普通股股本（每期都有）** |
| `TOTAL_MARKET_CAP` | 总市值（报告期末） |
| `PE_TTM` / `PB_TTM` | 接口自己算的 PE / PB（仅报告期末，非日频） |
| `FISCAL_YEAR` | 财年截止，如 `12-31` → 可识别 3/31 年结公司 |
| `CURRENCY` | 币种，00700 全部 96 期均为 `HKD` |
| `DATE_TYPE_CODE` / `ACCOUNT_STANDARD` | 报告类型码 / 会计准则 |

**批量按报告期取全市场**（与 A 股 `fetch_financials` 同构）：

```
filter=(REPORT_DATE='2026-06-30')
```

| 报告期 | count |
|---|---|
| 2026-06-30 | 2123 |
| 2025-12-31 | 2238 |
| 2020-12-31 | 2254 |

→ 每期约 2100~2250 只，pageSize=500 时约 5 页。

**备用纵表**（只需单个科目时更省流量）：

```
reportName=RPT_HKF10_FN_INCOME
STD_ITEM_CODE=004025002  →  股东应占溢利
STD_ITEM_CODE=004012999  →  除税后溢利
```
纵表是「一个科目一行」，单只单期就有 27 行，**不适合批量**；仅在需要主表缺失科目时兜底。

#### 报告期口径（重要）

东财对港股也生成了 `03-31 / 06-30 / 09-30 / 12-31` 四季数据（00700：03 期 24 条、
06 期 24 条、09 期 23 条、12 期 25 条）。但**港股法定只要求中报与年报**，
一季报/三季报是东财推算或公司自愿披露，可靠性不一致。

**决定：港股只采用 `06-30`（中报）与 `12-31`（年报）两期。**
代价是港股 TTM 半年才更新一次（A 股是季度），但口径可靠。

## 3. TTM 构造与 PE 自算（用 00700 实测演算）

`HOLDER_PROFIT` 是**累计值**，验证：

| 报告期 | HOLDER_PROFIT（亿 HKD） |
|---|---|
| 2026-03-31 | 580.93 |
| 2026-06-30 | 1141.15 |
| 2025-09-30 | 1665.82 |
| 2025-12-31 | 2248.42 |
| 2025-06-30 | 1034.49 |

`Q1(580.93) + Q2(560.22) = H1(1141.15)` ✅ 确认为累计口径。

TTM 公式与 A 股**完全相同**（`datasource.ttm_required_periods` 不用改）：

```
TTM(2026-06-30) = H1_2026 + FY_2025 − H1_2025
                = 1141.15 + 2248.42 − 1034.49
                = 2355.08 亿 HKD
```

PE：

```
PE = 总市值 / TTM 净利 = 3.8743e12 / 2.35508e11 ≈ 16.45
```

（对照接口自己给的 `PE_TTM = 14.52`，差异来自它用的市值基准日不同；我们按统一的
「当日市值 ÷ 当日已披露最新 TTM」口径，与 A 股一致。）

### 币种

`CURRENCY = HKD`，市值也是 HKD，**分子分母同币种，PE 无需换汇** ✅

> 整体法 `PE = Σw / Σ(w/PE_i)` 中 `w` 是基金披露的人民币权重占比，PE 无量纲，
> 所以港股用港币口径、A 股用人民币口径可以混在一起算，不需要汇率。

### 历史股本（精度优化）

`f84` 只有**当前**股本，直接乘历史收盘价会有偏差（腾讯近年回购使股本从约 95 亿降到 91 亿，约 4%）。

**用财报里的 `ISSUED_COMMON_SHARES` 按报告期做阶梯插值**，可得到每日股本，
把历史市值误差压到接近 0。这一步已经在主表字段里，不需要额外请求。

## 4. 已知限制

| 限制 | 影响 | 处理 |
|---|---|---|
| **无财报披露日** | PIT 无法按真实披露日对齐 | 退化为法定截止日：中报 8/31、年报 4/30（保守，与 A 股持仓的保守口径一致） |
| 港股 TTM 半年更新一次 | 港股增速曲线是阶梯状 | 界面标注；不影响 PEG 的量级判断 |
| 非 12-31 财年公司（如 3/31 年结） | TTM 会跨错年 | 读 `FISCAL_YEAR`，非 `12-31` 时标注并可选剔除 |
| 币种非 HKD 的公司（如 USD 记账） | 市值(HKD) ÷ 净利(USD) 会错 | 读 `CURRENCY` ≠ HKD 时告警 |
| `push2his` 限流敏感 | 批量抓 K 线易被掐 | 复用全局节流 + 退避 + 断点续传 |
| 4685 条清单含非股票 | 初始化浪费 | 过滤 5 位数字 + 有市值 + 财报里有 HOLDER_PROFIT |
