## Product Overview
在场外基金的分析结果「历史净值」K 线区块中，净值数字（如 1.7726）下方新增「当天预测」一行：按基金网站标准算法（最新定期报告的持仓成分股 × 当日实时涨跌 × 持仓权重加权求和）计算当日估算涨跌幅，盘中实时显示如「当天预测 +2.00%」。

## Core Features
- **当日估算涨跌**：公式 est_pct = Σ(持仓权重 × 该股当日涨跌幅) / 100（基金整体净值口径，现金/债券按 0 贡献，参考天天基金盘中估值算法）
- **A股成分股**：用现有实时行情接口的当日涨跌幅（2 分钟缓存，现成可用）
- **港股成分股**：新增东财 ulist 批量实时接口补齐当日涨跌幅（secids 前缀 116.，一次请求查多只，失败静默降级不计入）
- **覆盖率提示**：显示参与估算的持仓权重占比，明示估算口径（「按最新持仓成分股当日涨跌加权估算 · 覆盖 XX% 权重」）
- **仅场外基金显示**：ETF 有场内实时涨跌不需要此功能；红涨绿跌着色，与现有 K 线配色一致


## Tech Stack
- 后端：Python 标准库（复用现有 `http_get`/`_num`/`_jsonp_or_json`/`cache_get/cache_put` 基础设施，保持零第三方依赖）
- 数据源：东财 push2 实时行情（A股，现有 `fetch_realtime_quotes` 已带 pct 字段）+ 东财 ulist 批量接口（港股，新增）
- 前端：单文件 `web/index.html`，在现有 K 线区块头部追加显示

## Implementation Approach
1. **估算计算放在 `server.py` 的 `/api/analyze` 处理器内**（`analyze_etf` 返回后、`asdict(r)` 前计算，作为额外字段塞进返回 JSON），而非 `analyze_etf` 内部——批量扫描/排行（`analyze_many`）不触发港股实时拉取，避免限流；只有单只分析才计算
2. **A股涨跌**：`ds.fetch_realtime_quotes()`（返回 {code: {price, pct, ...}}，2 分钟缓存，够实时）
3. **港股涨跌**：新增 `fetch_hk_realtime_pct(codes)` 走东财 ulist 批量接口（`secids=116.xxx` 拼接，分批请求），60 秒缓存，失败返回空 dict（港股按无数据不计入，覆盖率如实下降）
4. **公式**：est_pct = Σ(w × pct) / 100（基金整体口径）；coverage = Σ(参与权重) / 100；仅场外基金计算（代码非 51/56/58/15 开头）
5. **前端显示**：K 线区块头部 `klinePrice`（净值数字）下方一行，「当天预测 +2.00%」（红涨绿跌）+ muted 小注说明口径与覆盖率；按 `KLN.kind === 'fund'` 判断显示（联接基金穿透后 CUR 是 ETF，kind=etf，自然不显示）

### 性能与可靠性
- A股行情走 2 分钟缓存、港股走 60 秒缓存，重复分析不重复回源
- 港股 ulist 分批（每批约 50 只 secids），单只基金持仓内港股通常 < 30 只，1~2 次请求搞定
- 估算失败（行情接口不可用）时返回 null，前端不显示预测行，不影响分析主流程
- 分析时刻快照，重新分析即刷新（不做前端轮询，避免限流）
